# Seam Carving Lab

内容感知图像缩放算法（Shai Avidan & Ariel Shamir, 2007）。优先去除平坦区域（背景、天空），保留边缘（人物、建筑）。

## 使用方法

打开 `index.html`，上传图片，点击"移除"即可。

- **缩减** — 控制要移除的 seam 数量
- **速度** — 1 最慢可观察过程，10 最快
- **遮罩** — 在能量图上涂抹：绿色保护（不裁剪该区域），红色强制移除
- **笔刷** — 遮罩画笔粗细

## 三栏画布

| 画布 | 内容 |
|------|------|
| 能量图 | 梯度热力图，黑→红→黄→白。可在此涂抹遮罩 |
| Seam 寻找 | 原图 + 绿色 seam 线 + 黄色端点 |
| 结果 | 裁切后的图像 |

## 算法

### 能量函数

用 Sobel 梯度近似，计算每个像素与四邻域在 RGB 三个通道上的平方差和的开方：

```
energy(x, y) = sqrt(dx² + dy²) + mask(x, y)
dx = (R右-R左)² + (G右-G左)² + (B右-B左)²
dy = (R下-R上)² + (G下-G上)² + (B下-B上)²
```

### DP 找 seam

```
dp[y][x] = energy[y][x] + min(dp[y-1][x-1], dp[y-1][x], dp[y-1][x+1])
```

从最后一行的最小值回溯到第一行，得到一条从顶到底的最小能量路径。

### 删除 seam

每行跳过 seam 列，剩余像素左移一格，图像宽度 -1。重复直到目标宽度。

### 遮罩

直接在能量值上加减偏移量，DP 自动规避保护区域、趋向移除区域。
